# MCP Intro Video Watchlist

Shortlisted introductory/overview videos about the Model Context Protocol (MCP),
curated for the team lunch-and-learn session. All entries are actual videos
(currently all hosted on YouTube), sourced via web video search.

## 1. The Model Context Protocol (MCP)

- **URL:** https://www.youtube.com/watch?v=CQywdSdi5iA
- **Duration:** 19:35
- **Publisher:** Anthropic (with Theo Chu, David Soria Parra, Alex Albert)
- **Why show it:** The protocol's creators explain it in their own words (David Soria Parra is an MCP co-architect) — the most authoritative overview available, straight from the source.

## 2. Model Context Protocol (MCP), clearly explained (why it matters)

## 3. you need to learn MCP RIGHT NOW!! (Model Context Protocol)
