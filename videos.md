# MCP Intro Video Watchlist

Shortlisted introductory/overview videos about the Model Context Protocol (MCP),
curated for the team lunch-and-learn session. Every entry is an actual video
(hosted on YouTube) — blog posts and documentation pages were deliberately
excluded.

For each entry: title, URL, duration (as reported by the video search index),
publisher, and a one-line note on why it is worth showing.

---

## 1. How Model Context Protocol (MCP) actually works

- **URL:** https://www.youtube.com/watch?v=cGuyrANVi4A
- **Duration:** 07:58
- **Publisher:** Google (Google Cloud / Google for Developers family)
- **Why show it:** The tightest credible walkthrough of the client-server architecture anyone has published — the fastest way to settle "what does MCP actually do underneath."

## 2. Model Context Protocol (MCP) Explained in 20 Minutes

- **URL:** https://www.youtube.com/watch?v=N3vHJcHBS-w
- **Duration:** 19:49
- **Publisher:** Shaw Talebi (free video course on YouTube)
- **Why show it:** A clean standards walkthrough of MCP, clients, and servers, plus a hands-on Python server demo connected to Claude Desktop — the closest thing to an "official" mental model for the team.

## 3. Understanding MCP From Scratch

- **URL:** https://www.youtube.com/watch?v=CDjjaTALI68
- **Duration:** 12:22
- **Publisher:** LangChain (the creator channel itself could not be independently confirmed from search metadata)
- **Why show it:** A friendly, ground-up primer built around the "USB-C port for AI applications" analogy — the best entry point for anyone who has never heard of MCP.

## 4. MCP In 26 Minutes (Model Context Protocol)

- **URL:** https://www.youtube.com/watch?v=kOhLoixrJXo
- **Duration:** 26:23
- **Publisher:** Tina Huang (ex-Meta data scientist; no-code + code tutorial)
- **Why show it:** Covers MCP definition, the Tools/Resources/Prompt primitives, the client-server communication life cycle, and how to build an MCP server both no-code and with code.

## 5. The Model Context Protocol (MCP)

- **URL:** https://www.youtube.com/watch?v=CQywdSdi5iA
- **Duration:** 19:35
- **Publisher:** Anthropic (with Theo Chu, David Soria Parra, Alex Albert)
- **Why show it:** The Anthropic team talking about the standard MCP was designed to standardize — David Soria Parra is the protocol's co-creator, so this is the most authoritative overview available, straight from the source.

## 6. Why we built—and donated—the Model Context Protocol (MCP)

- **URL:** https://www.youtube.com/watch?v=PLyCki2K0Lg
- **Duration:** 35:32
- **Publisher:** Anthropic (with co-creator David Soria Parra)
- **Why show it:** Includes the origin story behind MCP — how and why Anthropic released it as an open standard, which anchors *why* the team needs the protocol.

## 7. you need to learn MCP RIGHT NOW!! (Model Context Protocol)

- **URL:** https://www.youtube.com/watch?v=GuTcle5edjk
- **Duration:** 38:40
- **Publisher:** NetworkChuck
- **Why show it:** The most-watched MCP intro (~1.6M views on its course series) and runs real MCP servers with Claude Desktop, LM Studio, and Cursor — people see the protocol actually working.

## Suggested session flow

- **Opener:** Video 1 (Google, 8 min) or Video 3 (12 min) to set the stage.
- **Core:** Video 5 (Anthropic, 20 min) for the authoritative overview, then Video 2 (20 min) or Video 4 (26 min) for the plain-language primer.
- **Deeper dive:** Video 7 (NetworkChuck) for a hands-on session, or Video 6 (35 min) for the origin story.

## Provenance & caveats

- Compiled from Brave web/video search results; only actual videos were shortlisted — blog posts and documentation pages were deliberately excluded.
- Publishers were cross-checked against independent sources where possible; entries marked as not independently confirmed reflect attribution that could not be verified from search metadata.
- Durations are as reported by the video search index and may change over time.
